# INFT2201 Web Development Enterprise

This project is part of the INFT2201 Web Development Enterprise class. It encompasses various components critical for modern web development, including:

- **PHP**: Used for server-side scripting to build dynamic web pages.
- **JavaScript**: Implemented for client-side logic and enhancing user interactivity.
- **Docker**: Utilized for containerization to ensure consistent development and deployment environments.
- **HTML**: The backbone of web content structure, providing layout and functionality.
- **Shell**: Employed for scripting and automation tasks within the development workflow.

This README serves to provide an overview of the project and its technological landscape.
